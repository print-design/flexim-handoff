Flexim — дизайн-система (Bootstrap 4)

Та же дизайн-система, что в React-каталоге, но реализованная через Bootstrap 4.0.0 + jQuery 3.5.1 + _bootstrap-flexim-overrides.css. Эту страницу и стили можно показать программисту — он подключит overrides в прод и весь сайт сразу станет брендовым.

Рабочий пример — настоящие <input> для форм

Для рабочих форм (логин, фильтры с ручным вводом, любые поля) внутрь .flexim-input__content кладём <input class="flexim-input__field">. Фокус-рамка появляется автоматически через :focus-within. Матрица сверху — это витрина состояний для дизайн-сверки, в проде её разметку не использовать.

Action-slot — кнопка-действие в поле

Универсальный слот .flexim-input__action для кнопок-иконок справа от поля: eye toggle для пароля, copy, paste и т.п. Геометрия и стилизация совпадают с .flexim-input__clear, но семантика разная: __clear — «крестик очистки значения», __action — любое другое действие. Цвет иконки: бренд-розовый по умолчанию, серый в disabled, hover на бренд-light.
