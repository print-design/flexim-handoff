Flexim — handoff

Дизайн-система для интеграции в прод print-design/pr-diz.ru.

Перед началом — README.md: что и в каком порядке подключать (две строки <link> + один <script> + папка icons/).

Точки входа в пакет

  • components.html Каталог компонентов — источник истины. Бери разметку 1:1.
  • 01-orders.html Эталон экрана-списка: рейка + шапка + page-header + полная таблица + пагинация.
  • 02-order-card.html Эталон карточки заказа: вкладки + левая сводка + правый расчёт.
  • icons.html Все иконки реестра в одном месте — поиск нужной по имени.
  • _template.html Пустая болванка для новых страниц с уже подключёнными стилями.

Документация

  • RULES.md Свод правил и частых ошибок (hover-конвенция, пагинация, full-height таблицы и т.д.).
  • COMPONENTS.md Список компонентов с описаниями и пропсами.
